# 冻结盲测发布门禁

`thalion-release-gate` 离线核验冻结清单和候选版本的观测记录。它不访问数据库、不调用候选服务、不上传语料。仓库 CI 只验证工具和测试夹具；正式发布应在独立的私有流程中使用真实制度盲测。

## 准备和执行

1. 制度负责人在候选构建前批准脱敏语料、题集、案例和阈值。题集应冻结角色、业务日期、检索条数、可接受证据、禁止披露范围和复核规则。分别对语料快照和题集的确切字节取 SHA-256，再将两者写入清单。将清单摘要保存到受保护的发布配置，不从观测记录临时取值。
2. 构建流程记录待发布 wheel 或镜像的 SHA-256。评估人员在已核对制品和配置的隔离环境中运行 HTTP、MCP 用例，记录每次调用的实测结果和耗时。保留原始调用记录与候选环境证明，限制访问，不把正式题集、凭证或原始响应放进公开 CI。
3. 生成用例由两名独立复核人逐条核查。分母包含输出中的全部事实主张，而不是仅统计有引用的主张；分别记录引用指向相关证据和证据足以支撑该事实的数量。保留两人的原始复核记录，以便追溯差异。观测只填经过复核的结果和不含个人信息的代号。
4. 私有发布任务从受保护的配置和构建记录取得预期摘要，从受信评估流程取得观测，再运行：

```bash
thalion-release-gate suite.json observations.json \
  --suite-sha256 "$APPROVED_SUITE_SHA256" \
  --artifact-sha256 "$CANDIDATE_ARTIFACT_SHA256"
```

退出码为 `0` 才允许后续发布，同一制品摘要必须贯穿评估和发布。`1` 表示观测完整但未达标，`2` 表示输入不可读、格式无效或不匹配。发布任务只需归档聚合报告；不要把观测明细写入流水线日志。

## 输入约定（`schema: 1`）

两份文件都使用 UTF-8 JSON，每份最多 4 MiB。摘要为 64 位小写十六进制 SHA-256。清单和观测不容许额外字段或重复 JSON 键。

- 清单包含 `schema`、`dataset_kind`（必须为 `approved_blind`）、`query_set_sha256`、`corpus_sha256`、`thresholds`、`cases`。每个案例只记非敏感 `id` 和 `kind`，至少覆盖 `retrieval`、`historical`、`no_evidence`、`revocation`、`wiki` 五种类型。
- `thresholds` 包含 `top_k_hit_rate`、`historical_hit_rate`、`correct_abstention_rate`、`citation_support_rate`、`generation_support_rate`（均大于 0、不超过 1）和 `p95_ms`。每个入口单独达标。撤权拒绝率固定为 100%，所有用例的未授权披露数必须为零。
- 观测包含 `schema`、`suite_sha256`、`artifact_sha256`、`query_set_sha256`、`corpus_sha256` 和 `results`。每个案例必须有一条 `http` 和一条 `mcp` 记录。每条记录包含 `id`、`entrance`、`elapsed_ms`、`disclosures`、`status`。`retrieval`、`historical` 另含 `hit`（是否在冻结范围内命中允许证据）。拒答须为 `no_evidence`；撤权须为 `no_evidence` 或 `rejected`；服务故障不当成正确拒答。
- `wiki` 另含 `claims`、`citation_supported`、`factually_supported` 和两个不同的 `reviewers` 代号。无可评主张、漏测或未授权披露均不放行。候选环境若只支持从一个入口触发生成，不得把该响应复制为两个入口的观测；应记录实际评估链路，并核对各入口返回的 Wiki 内容及引用。

**当前边界：** 该命令只检查输入一致性和阈值。摘要匹配不能证明观测真实，复核代号不同也不能证明身份独立。当前仓库不提供正式盲测语料、生产观测采集器或已接入的私有发布任务；部署方须提供受信观测、批准记录和对应环境的实际验收结果。
